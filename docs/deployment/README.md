# Deployment guides

Read the [compatibility matrix](compatibility.md) first. Then choose:

- [Docker](docker.md) or [Docker Compose](docker-compose.md)
- [Podman](podman.md)
- [Kubernetes and Helm](kubernetes.md)
- [Linux bare metal](linux-bare-metal.md)
- [Proxmox LXC](proxmox-lxc.md)
- [Unraid](unraid.md)
- [Raspberry Pi](raspberry-pi.md)
- [macOS](macos.md)
- [Windows](windows.md)

All use the same `lumen` binary and config schema. These files do not change DNS
logic. A guide is not proof that its platform passed runtime tests; use the matrix.
